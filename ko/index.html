01 · 공공 데이터 분석 · Python / Tableau

프로모션은 언제 효과가 크고, 경쟁점 출점은 매출을 얼마나 줄일까?

독일 드러그스토어 체인 Rossmann 1,115개 매장의 일별 매출 약 100만 건을 분석해, 같은 프로모션이 시점에 따라 효과가 어떻게 달라지는지, 인근에 경쟁점이 생기면 매출이 얼마나 줄어드는지 측정했습니다.

데이터
Kaggle Rossmann Store Sales · 일별 매출, 2013년 1월 – 2015년 7월
도구
Python (pandas, statsmodels), Tableau · 코딩 보조로 Claude Code 활용, 모든 결과는 데이터로 재검증
결과
프로모션은 수요가 약할 때 효과가 가장 컸습니다(월중 +38% vs. 월초·월말 +29%, 비수기 +43–44% vs. 성수기 +29–31%). 500m 이내 경쟁점 출점 시 매출은 20% 감소했고, 12개월 넘게 회복되지 않았습니다.
판단
경쟁점이 가까운 매장의 매출이 오히려 더 높게 나오자 입지 효과를 의심하고, 같은 매장의 출점 전후 비교로 방법을 바꿨습니다.

개인 프로젝트 · 2026 · 할인·프로모션 비용 데이터가 없어, 효과는 이익이 아닌 매출 기준입니다.

02 · 데이터 정제 · SQL (SQLite)

분석 전, 데이터 오류 1,337건 정제

더마 화장품 브랜드의 상품 마스터와 주문 데이터를 SQL로 점검·정제한 뒤, 채널별 전년 대비 성장률과 브랜드 라인·SKU별 매출총이익률을 분석했습니다.

데이터
직접 생성한 가상 데이터 · SKU 29개 · 채널 10개 · 시장 5개 · 주문라인 52,525건 (2025년 1월 – 2026년 10월)
도구
SQL (SQLite), 가상 데이터 생성용 Python · 코딩 보조로 Claude Code 활용, 모든 결과는 쿼리 재실행으로 재검증
정제
규칙 11개로 오류 1,337건을 찾아 수정했고, 정제 테이블에 같은 규칙을 다시 적용한 결과 11개 모두 0건이었습니다. 원본 테이블은 그대로 보존했습니다.
분석
채널별 성장률 편차가 컸고(큐텐 재팬 +90.4%, 면세점 −27.6%), 아크네 클리어 라인의 매출총이익률은 53.9%로 전사 평균 67.0%를 밑돌았습니다.

개인 프로젝트 · 2026 · 가상 데이터이므로, 수치 자체보다 정제·검증·집계 과정을 보여주는 데 목적이 있습니다.
